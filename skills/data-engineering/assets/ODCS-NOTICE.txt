The bundled data contract template targets Open Data Contract Standard (ODCS) v3.1.0.

Normative specification:
https://bitol-io.github.io/open-data-contract-standard/v3.1.0/

Upstream project:
https://github.com/bitol-io/open-data-contract-standard

ODCS is licensed under Apache License 2.0. The compact
data-contract-profile.schema.json in this repository is an independently written,
non-normative validation profile for the fields used by the bundled template. It
does not replace or reproduce the upstream schema. If this profile conflicts with
the normative standard, the normative standard takes precedence.
